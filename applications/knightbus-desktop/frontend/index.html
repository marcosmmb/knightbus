Service setup

  
KnightBus uses a background process named knightbusd to handle devices. The app connects to that process.

  
  1. Choose Start local service to restart the installed service, or run the bundled account service. macOS may ask for administrator approval.
  2. If the companion is missing, reinstall the complete KnightBus package. On macOS it belongs inside KnightBus.app; on Windows keep knightbusd.exe next to the app.
  3. For an existing system service, use Connection settings to check its endpoint, then retry. Use its installer to repair permissions or mismatched versions.

  
The first Share device action on macOS offers administrator setup for USB capture. Windows USB import requires the USB/IP driver included with the KnightBus installer.
